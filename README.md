# Blood Donation Prediction

A machine-learning classification project using the UCI Blood Transfusion Service Center dataset to explore patterns in historical donor behaviour.

## Objective
Use donor history features to build a model that predicts the donation outcome represented in the dataset.

## Workflow
- Load and inspect the dataset.
- Perform exploratory data analysis.
- Prepare features and target variable.
- Train and evaluate a classification model.
- Save the trained model and preprocessing object for reuse.

## Dataset
[UCI Blood Transfusion Service Center dataset](https://archive.ics.uci.edu/ml/machine-learning-databases/blood-transfusion/transfusion.data)

## Technologies
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn · Jupyter Notebook

## Key concepts
Data Exploration · Data Preprocessing · Classification · Model Evaluation · Model Serialization

*This is an educational project based on historical data; predictions should not be used to make individual medical or donor-eligibility decisions.*
