# Blood Donation Prediction

A machine-learning project focused on predicting blood donation behaviour using historical blood-transfusion data.

## Project objective

Explore donor-related data and build a classification workflow that can estimate whether a person is likely to donate blood, based on the features available in the dataset.

## Dataset

The project is based on the UCI Blood Transfusion Service Center dataset.

Dataset source: https://archive.ics.uci.edu/ml/machine-learning-databases/blood-transfusion/transfusion.data

## Typical project workflow

- Load and inspect the dataset.
- Perform exploratory data analysis (EDA).
- Check data quality and prepare features.
- Split data into training and testing sets.
- Train and evaluate a classification model.
- Save the trained model and preprocessing object when required for reuse.

## Tools and libraries

- Python
- Jupyter Notebook
- Pandas and NumPy
- Matplotlib / Seaborn
- Scikit-learn

## Skills demonstrated

Data analysis · Data preprocessing · Classification · Model evaluation · Model persistence

## How to run

1. Clone or download this repository.
2. Open the notebook in Jupyter Notebook or JupyterLab.
3. Install the libraries used in the notebook.
4. Ensure the dataset is available at the path expected by the notebook.
5. Run the notebook cells in order.
