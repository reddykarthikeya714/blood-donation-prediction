# Blood Donation Prediction

A machine-learning classification project using historical blood-transfusion data to explore whether donor-related attributes can help estimate future blood donation behaviour.

## Project at a glance

| Item | Details |
|---|---|
| Problem type | Binary classification |
| Domain | Healthcare analytics / donor behaviour |
| Dataset | UCI Blood Transfusion Service Center |
| Main tools | Python, Pandas, NumPy, Scikit-learn |

## Objective

Explore the available donor history features and build a classification workflow to predict the donation outcome represented in the dataset. This is an educational machine-learning project, not a clinical or operational decision system.

## Dataset

The project uses the **UCI Blood Transfusion Service Center** dataset.

Dataset source: [UCI dataset file](https://archive.ics.uci.edu/ml/machine-learning-databases/blood-transfusion/transfusion.data)

## Workflow

1. Load the dataset and inspect columns, data types, and summary statistics.
2. Perform exploratory data analysis to understand feature patterns and the target distribution.
3. Prepare the input features and target variable.
4. Split the data for model development and evaluation.
5. Train and evaluate a classification model.
6. Save the trained model and preprocessing object for reuse where applicable.

## Tools and technologies

- Python and Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Pickle for saving model artifacts

## Skills demonstrated

Data exploration · Data preprocessing · Classification · Model evaluation · Model serialization · Working with a public healthcare dataset

## Run locally

1. Clone this repository.
2. Open the notebook in Jupyter Notebook or JupyterLab.
3. Install the Python libraries imported by the notebook.
4. Download the dataset from the source above and update the file path in the notebook.
5. Run the notebook cells in order.

## Responsible-use note

The dataset is historical and limited. Predictions should not be used to make decisions about an individual's eligibility for blood donation or to replace professional medical guidance. Check model performance, class-level errors, and data limitations before considering any real-world use.
