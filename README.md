# Blood Donation Prediction

A supervised machine-learning project exploring whether a person is likely to donate blood again, using historical blood-transfusion data.

## Project objective
Use donor-history features to build a classification workflow and understand how past donation behaviour can support prediction.

## Dataset
The project uses the **UCI Blood Transfusion Service Center** dataset.

Dataset source: https://archive.ics.uci.edu/ml/machine-learning-databases/blood-transfusion/transfusion.data

## Workflow
1. Load the dataset and inspect its structure.
2. Explore feature distributions and the target variable.
3. Prepare the data for machine learning.
4. Split the data into training and testing sets.
5. Train and evaluate a classification model.
6. Save the trained model and preprocessing object for reuse, where applicable.

## Tools
- Python and Jupyter Notebook
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn

## Skills demonstrated
Data exploration · Data preprocessing · Classification · Model evaluation · Saving and reusing ML models

## Run the project
1. Clone or download this repository.
2. Open the notebook in Jupyter Notebook, JupyterLab, or Google Colab.
3. Install the required Python libraries.
4. Make sure the dataset path matches your local setup.
5. Run the notebook cells in order.

## Notes
Model performance should be judged using the evaluation results in the notebook. No accuracy or other metric is claimed here without a verified result.
